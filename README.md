# KH Remaster Forecast — Red Rework

A fan-made NSAP/KH Remaster forecasting dashboard. It is a static website: no build step, server, framework, or backend required.

## Files
- `index.html` — structure and dialogs
- `styles.css` — red NSAP-inspired responsive design
- `app.js` — forecast engine, editable database, timeline, local storage, import/export and history

## New in the rework
- Fully red/black visual identity
- Control Room for editing forecast labels, descriptions and base score
- Add evidence with type, status and weight
- Add timeline events
- Search/filter evidence
- Export/import all saved data as JSON
- Forecast snapshots
- Local browser persistence
- Reset button
- Responsive mobile layout
- Share button

## Run
Open `index.html` in a browser.

## Important
This is a fan-made tracker. Confirmed facts, developer clues, leaks/WIP and theories should remain clearly separated. The score is an estimate, not an official announcement.


## Max edition controls

The Control Room lets you edit forecast labels/descriptions, change the base score, keep local admin notes, export/import all tracker data, restore defaults, and clear forecast history. Evidence can be added from the evidence dialog and timeline events can be added from the timeline controls.

The dashboard is intentionally local-first: there is no authentication or server database. Do not put passwords, tokens, or other secrets into admin notes or exports.
